## 2. Исследовательские треки (день 1), в порядке ценности для жюри
Для каждого трека ИИ пишет отчёт `results/track_X.md`: гипотеза → метод → результат → статус.

### R1. Структура произвольных слов («связанный Коллатц»). Главный кандидат на оригинальность
*Идея:* после ⌈L/2⌉ шагов любое слово является конкатенацией блоков БББ | АВ | Б. Блоки нечётной длины (БББ, Б) сдвигают фазу чтения на 1.
Значит, слово описывается последовательностью длин серий Б между «маркерами» АВ плюс битом фазы.
- [ ] Написать `src/tagsys/runs.py`: слово → (фаза, [n1, n2, …]) и обратно; проверить биективность на всех словах в нормальной форме длины ≤ 20.
- [ ] Найти правило перехода «макрошага» для 2 серий: (n1, n2, фаза) → (n1', n2', фаза'). Гипотеза: каждая серия эволюционирует по T, а чётность одной серии переключает фазу для следующей (перенос, как в сумматоре).
- [ ] Если правило найдено: сформулировать теорему «произвольное слово ≅ многомерное отображение Коллатца с переносом чётности» и доказать её для 2 серий.
- [ ] Объяснить, **почему появляются циклы** (в чистом Коллатце на натуральных числах их нет): связь серий создаёт новые периодические орбиты. Проверить на каталоге `results/cycles.csv`.
- **Критерий успеха:** явная формула перехода, проверенная на всех словах до 20 букв. Даже частичный результат (2 серии) уже сильный.

### R2. Каталог и семейства циклов
Сейчас известно 10 циклов до L=25 (периоды 4, 20, 40, 88, 100, 100, 100, 120), семейство X^kA бесконечно (Т4).
- [ ] Прогнать `./csrc/enum 26 28` (минуты; при нехватке времени хватит 26).
- [ ] Для каждого цикла искать «накачку»: подслово Y, такое что вставка Y^k сохраняет цикличность (перебор позиций и |Y| ≤ 16). Цель: разбить все циклы на бесконечные семейства и сформулировать гипотезу «все циклы принадлежат конечному числу семейств».
- [ ] Посчитать число циклов с минимальной длиной ≤ L как функцию L и построить график.

### R3. Неограниченный рост
- [ ] Доказать, что в исходной системе (q=3) для слов Б^n неограниченный рост ⇔ расходящаяся траектория Коллатца (следует из Т3).
- [ ] Теорема 3' (`T_q`, уже в коде): при q=4 слово Б^3 растёт неограниченно. Это **доказанный пример третьего исхода** в соседней системе. Вывод: исход «рост» не запрещён механизмом tag-систем, его исключение для q=3 — чистая арифметика.
- [ ] Эвристика дрейфа: средний ln-множитель за макрошаг равен ½·ln(q/4), отрицательный только при q<4. Проверить численно распределение ln(Б-длины) по макрошагам для q=3 и q=5 (график). Это аргумент «почему жюри выбрало именно 3».

### R4. Статистика времени остановки
- [ ] S(n) = Σ(m + m mod 2) по орбите (доказано). Сравнить S(n)/n с «интегралом траектории» Коллатца; построить распределение log S(n) − log n.
- [ ] Сопоставить с моделью Лагариаса–Вейса (среднее время остановки ≈ 6.95·ln n макрошагов для T). Оценить матожидание S(n) через случайное блуждание.

### R5. Двухбуквенный алфавит — оформить три уровня ответа
1. **Блочный код** (читаем 2 последние, стираем 4): точная симуляция, доказательство через гомоморфизм кодирования. Готово.
2. **Циклическая tag-система Кука** (читаем 1 бит, стираем 1, но продукция зависит от номера шага по модулю 6): готово. Честно оговорить, что правила зависят от номера шага.
3. **«Чистая» tag-система на {А, Б}** (правило зависит только от последней буквы): перебор (`csrc/search_binary.c`) не нашёл ни одной в диапазоне d ≤ 6, |продукции| ≤ 8, кодировки X^n и X^nY. Сослаться на De Mol (разрешимость TS(2,2)) и Neary 2015 (двоичные tag-системы универсальны, значит такие системы существуют при больших d, но огромные).
- [ ] Расширить перебор: кодировки X^n Y Z, d ≤ 8 (C, по ядрам, `#pragma omp parallel for`). Записать точные границы перебора.

### R6 (опционально, «вау»). Формальная проверка
- [ ] Lean 4 + Mathlib: формализовать Т3 (индукция по k для (АВ)^k и Б^{3k}А) и Т4 (прямое вычисление `decide` для k=1 плюс индукция). Ориентир — проект ccchallenge.org (формализация литературы о Коллатце). Если за 4 часа не выходит, бросить и упомянуть как направление.
- [ ] Альтернатива: попытка доказать завершаемость ослабленных вариантов через SAT-поиск интерпретаций по методу Yolcu–Aaronson–Heule (2021). Например: «все слова без буквы В останавливаются?» — сначала проверить перебором.
