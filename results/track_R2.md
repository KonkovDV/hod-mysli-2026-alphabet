# Трек R2. Каталог и семейства циклов

## Гипотеза

Все циклы принадлежат конечному числу бесконечных семейств, получаемых накачкой блока.

## Метод

Каталог: `results/cycles.csv` и, если есть, `results/cycles_26_28.txt`. Перебор классов: `results/enumeration.csv` плюс `enumeration_26_28.csv`. Максимальная длина в таблице: 28. Для каждого цикла орбита переведена в координаты серий. Накачка: каждый подблок серий длины ≤ 4 повторяется k=2,3,4 раза; считается успехом цикл с μ=0 (само слово уже на цикле).

Все растущие накачки — окна одного явления. Его чистая форма — семейство σ_k: фаза 0, серии (0, 9, 0, 0, 0) + (0, 5, 0, 3)^k. Проверено для k=1…24: совпало 24 из 24. Период равен 20 при k=1 (это уже известный цикл периода 20) и 40+60k при k≥2. Статус общей формулы при всех k: **гипотеза**, подтверждённая указанным перебором. Доказательства для всех k в этой работе нет: лишний блок вдоль орбиты меняет форму, и индукция не сводится к одной строке, как в теореме 4.
