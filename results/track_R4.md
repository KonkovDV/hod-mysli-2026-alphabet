# Трек R4. Статистика времени остановки

## Гипотеза

S(n)/n сравнимо с суммой геометрической прогрессии со знаменателем sqrt(3/4), а число макрошагов T — с (2/ln(4/3)) ln n (модель Лагариаса–Вейса для ускоренного отображения).

## Метод

Для n от 2 до 8000 орбита T и формула S(n) считаются напрямую, без ручных констант.

## Результат

S(27) = 40656, максимум орбиты и максимум длины слова Б^27 = 4616, макрошагов T до 1: 70.

Константа модели макрошагов 2/ln(4/3) = 6.95212. По выборке n=100…8000: среднее (число макрошагов)/ln n = 6.89091, медиана = 5.82006.

Среднее S(n)/n = 51.2585, медиана = 14.4036, среднее ln(S/n) = 2.78347. Модельный множитель 1/(1−sqrt(3/4)) = 7.4641 (натуральный логарифм этого множителя = 2.01011).

Рисунок: `figures/log_S_ratio.png`. Тяжёлый хвост — длинные экскурсии, как у n=27.

## Статус

- Формула S(n): **доказано** при условии, что орбита доходит до 1.
- Численные средние: **проверено** на указанном диапазоне.
- Совпадение числа макрошагов с 2/ln(4/3): **гипотеза** случайной модели; среднее по выборке к ней близко, медиана меньше из-за асимметрии.
- Множитель 1/(1−sqrt(3/4)) для S(n)/n: **гипотеза**. Он даёт правильный порядок, но медиана S/n примерно вдвое больше: модель не учитывает корреляции чётности и хвост экскурсий.
